Holiday Records — Cross-System Comparison

Each tab in the Excel file is one system. Pick the source system, and see which currency/date holidays match or are missing across the others. Everything runs in your browser — your file is never uploaded.

Tip: the tab/sheet name is used as the system name — an in-sheet “System” column is ignored. Dates default to MM/DD/YYYY.
